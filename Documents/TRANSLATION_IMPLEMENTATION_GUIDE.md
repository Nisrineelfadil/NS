# Translation Implementation Guide

## Problem
The German translations have been added to `/js/translations.js`, but they're not appearing on the page because the HTML/JavaScript code needs to be updated to USE these translations.

## Solution

The student management system appears to be dynamically generated by JavaScript. To make the translations work, you need to:

### Option 1: Add data-i18n Attributes (Recommended)

If the HTML is in `student-management.html`, add `data-i18n` attributes to elements:

```html
<!-- BEFORE -->
<h1>Academic Seasons</h1>

<!-- AFTER -->
<h1 data-i18n="academicSeasons">Academic Seasons</h1>
```

Then make sure the page calls `translatePage()` on load:

```javascript
document.addEventListener('DOMContentLoaded', () => {
    translatePage();
});
```

### Option 2: Use Translation Function in JavaScript

If the content is generated by JavaScript, use the `t()` function:

```javascript
// BEFORE
const title = 'Academic Seasons';

// AFTER  
const title = t('academicSeasons');
```


## Example Implementation

### If Using HTML with data-i18n:

```html
<div class="page-header">
    <h1 data-i18n="academicSeasons">Academic Seasons</h1>
    <p data-i18n="manageAcademicYears">Manage academic years and their associated groups</p>
    <button data-i18n="createSeason">Create Season</button>
</div>
```

### If Using JavaScript to Generate HTML:

```javascript
function renderHeader() {
    return `
        <div class="page-header">
            <h1>${t('academicSeasons')}</h1>
            <p>${t('manageAcademicYears')}</p>
            <button>${t('createSeason')}</button>
        </div>
    `;
}
```
