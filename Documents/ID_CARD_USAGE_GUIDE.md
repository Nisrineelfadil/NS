## 🖨️ Printing the Card

### Step-by-Step Print Process

```
1. Click "Imprimer la Carte" button
   ↓
2. Browser print dialog opens
   ┌─────────────────────────────────┐
   │  Print                          │
   ├─────────────────────────────────┤
   │  Printer: [Select Printer ▼]   │
   │  Copies: [1]                    │
   │  Layout: [Portrait ▼]           │
   │  Color: [Color ▼]               │
   │                                 │
   │  [Cancel]  [Print]              │
   └─────────────────────────────────┘
   ↓
3. Select your printer
   ↓
4. Choose settings:
   • Copies: 1 (or more)
   • Layout: Portrait
   • Color: Color (recommended)
   • Paper: Card stock (recommended)
   ↓
5. Click "Print"
   ↓
6. Done! ✅
```

**Pro Tips**:
- 📄 Use thick card stock paper for durability
- 🎨 Use color printer for best results
- 🔄 Print both sides separately if needed
- 📏 Check print preview before printing

## 🔍 Troubleshooting Visual Guide

### Issue: Button Not Visible

```
❌ PROBLEM:
┌──────────────┐
│  [Photo]     │
│  John Doe    │
│              │
│  [👁] [✏️]   │  ← ID card button missing!
└──────────────┘

✅ SOLUTION:
1. Refresh the page (F5)
2. Clear browser cache
3. Check if student-id-card.js is loaded
4. Check browser console for errors
```

### Issue: Card Not Generating

```
❌ PROBLEM:
Click button → Nothing happens

✅ SOLUTION:
1. Open browser console (F12)
2. Look for JavaScript errors
3. Check if libraries are loaded:
   • JsBarcode
   • QRCode.js
   • html2pdf.js
4. Refresh page and try again
```

### Issue: Print Layout Broken

```
❌ PROBLEM:
Print preview shows wrong layout

✅ SOLUTION:
1. Use Chrome or Firefox (recommended)
2. Check print settings:
   • Orientation: Portrait
   • Margins: Default
   • Scale: 100%
3. Try PDF download instead
```

## 🎓 Best Practices

### For Best Results

1. **Photo Quality**
   - Use high-resolution photos (min 800x1000px)
   - Ensure good lighting
   - Professional appearance

2. **Printing**
   - Use card stock paper (250-300 GSM)
   - Color printer recommended
   - Check print preview first
   - Print test card before batch

3. **Security**
   - Print in secure location
   - Store printed cards safely
   - Don't share digital cards publicly
   - Password visible on back side

4. **Maintenance**
   - Update student photos regularly
   - Verify information before printing
   - Keep digital backups (PDF)
   - Replace damaged cards promptly
