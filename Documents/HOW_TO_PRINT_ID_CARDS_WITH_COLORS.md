# 🎨 Comment Imprimer/Télécharger les Cartes avec les Couleurs

## ⚠️ IMPORTANT: Activer les Graphiques d'Arrière-Plan

Pour que les couleurs du drapeau allemand (Noir, Rouge, Jaune) s'affichent dans le PDF, vous **DEVEZ** activer les graphiques d'arrière-plan dans votre navigateur.

---

## 🖨️ Instructions par Navigateur

### Google Chrome / Microsoft Edge

1. Cliquez sur **"Télécharger PDF"** ou **"Imprimer la Carte"**
2. Dans la fenêtre d'impression qui s'ouvre:
   - Cliquez sur **"Plus de paramètres"** ou **"More settings"**
   - ✅ **COCHEZ** la case **"Graphiques d'arrière-plan"** ou **"Background graphics"**
3. Sélectionnez **"Enregistrer au format PDF"** comme destination
4. Cliquez sur **"Enregistrer"**
5. Choisissez l'emplacement et le nom du fichier

### Firefox

1. Cliquez sur **"Télécharger PDF"** ou **"Imprimer la Carte"**
2. Dans la fenêtre d'impression:
   - Cliquez sur **"Paramètres de page"** ou **"Page Setup"**
   - Allez dans l'onglet **"Marges et en-tête/pied de page"**
   - ✅ **COCHEZ** **"Imprimer l'arrière-plan (couleurs et images)"**
3. Sélectionnez **"Microsoft Print to PDF"** comme imprimante
4. Cliquez sur **"Imprimer"**
5. Choisissez l'emplacement et le nom du fichier

## 💡 Astuces

### Si les couleurs ne s'affichent toujours pas:

1. **Vérifiez l'aperçu avant d'imprimer**
   - Les couleurs doivent être visibles dans l'aperçu
   - Si elles ne sont pas visibles, les graphiques d'arrière-plan ne sont pas activés

2. **Essayez un autre navigateur**
   - Chrome et Edge fonctionnent le mieux
   - Firefox nécessite plus de configuration

3. **Utilisez "Imprimer la Carte" au lieu de "Télécharger PDF"**
   - Les deux boutons font la même chose
   - Mais "Imprimer" est plus direct

4. **Vérifiez les paramètres de votre imprimante PDF**
   - Certaines imprimantes PDF ont leurs propres paramètres
   - Cherchez "couleur" ou "color" dans les options

## 🆘 Dépannage

### Problème: Le PDF est vide
**Solution**: Attendez que la carte soit complètement chargée avant d'imprimer

### Problème: Pas de couleurs dans le PDF
**Solution**: Activez "Graphiques d'arrière-plan" dans les paramètres d'impression

### Problème: Le mot de passe montre des astérisques
**Solution**: C'est normal, le vrai mot de passe s'affiche maintenant

### Problème: Le code-barres ne s'affiche pas
**Solution**: Attendez 1-2 secondes après l'ouverture de la carte avant d'imprimer
