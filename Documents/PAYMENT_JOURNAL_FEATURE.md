# Payment Journal (Journal de Paiement) Feature

## Overview

The Payment Journal feature provides a comprehensive PDF export of all payment history for individual students. This allows administrators to track and document all payments made by a student throughout their enrollment.

---

## ✨ Features

### 1. **Automatic Payment History Tracking**
- Every time an admin marks a payment as "paid", a record is automatically created in the payment history
- Tracks the following information:
  - Student name
  - Payment amount (in MAD)
  - Day of payment (the actual payment date)
  - Date marked as paid (when admin clicked "Mark as Paid")
  - Admin who marked the payment
  - Student's language group and branch

### 2. **PDF Export**
- Simple, readable PDF format
- Professional layout with school branding
- Includes:
  - School logo and name
  - Student information (name, language group, branch)
  - Complete payment history table
  - Footer with school attribution
- File size: 1-1.5 MB maximum
- Automatic compression for optimal size

### 3. **UI Integration**
- **Location**: Student profile modal → Quick Actions section
- **Button**: "Export Payment Journal" with golden gradient styling
- **Position**: Above the "Mark as Paid" button
- **Icon**: File invoice icon (📄)

## 📋 PDF Content Structure

### Header
- **School Logo**: Top-left corner (60x60px)
- **School Name**: "Nisrine School"
- **Subtitle**: "German Language Center - Fez, Morocco"
- **Title**: "Journal de Paiement / Payment Journal"
- **Generation Date**: Current date in French format

### Student Information Section
- **Full Name**: Student's complete name
- **Language Group**: Formation(s) enrolled (e.g., Allemand, Anglais, Français)
- **Branch**: Branch subgroup if enrolled (e.g., Gériatrie, Informatique)

### Payment History Table
Four columns:
1. **Full Name**: Student name for each payment
2. **Price (MAD)**: Payment amount in Moroccan Dirhams
3. **Day of Payment**: The date the student actually paid
4. **Date Marked as Paid**: The date the admin marked it as paid in the system

Features:
- Alternating row colors for readability
- Sorted by payment date (newest first)
- Handles empty history gracefully
- Automatic pagination for long payment histories

### Footer
- **Text**: "Generated by the admins of Nisrine School"
- **Style**: Italicized, centered, gray color

## 🔧 Technical Implementation

### Files Created

#### 1. **PaymentHistory Model** (`models/PaymentHistory.js`)
```javascript
{
    student: ObjectId,           // Reference to ManagedStudent
    studentName: String,         // Student's full name
    amount: Number,              // Payment amount in MAD
    paymentDate: Date,           // Actual payment date
    markedAsPaidDate: Date,      // When admin marked as paid
    markedBy: ObjectId,          // Admin who marked it
    markedByName: String,        // Admin's username
    formation: [String],         // Language groups
    branch: String,              // Branch subgroup
    notes: String,               // Additional notes
    createdAt: Date              // Record creation timestamp
}
```

**Indexes**:
- `student + createdAt` (for efficient queries)
- `student + paymentDate` (for sorting)

#### 2. **Payment Journal Generator** (`services/paymentJournalGenerator.js`)
- Uses PDFKit library
- Generates A4 size PDF with compression
- Handles pagination automatically
- Includes school logo and branding
- Creates professional table layout
- Validates file size (1.5 MB max)

#### 3. **API Endpoint** (`routes/studentManagement.js`)
```
GET /api/student-management/students/:id/payment-journal
```

**Authentication**: Requires admin JWT token

**Response**: PDF file download

**Headers**:
- `Content-Type: application/pdf`
- `Content-Disposition: attachment; filename="Payment-Journal-{StudentName}.pdf"`

#### 4. **Frontend Integration** (`js/phase2-student-profile.js`)
- Added "Export Payment Journal" button
- Golden gradient styling (#FFCC00 → #FF9500)
- Positioned above "Mark as Paid" button
- Handles PDF download with progress notifications

### Files Modified

## 🚀 Usage

### For Administrators

1. **View Student Profile**:
   - Navigate to Student Management
   - Click on a student to open their profile

2. **Export Payment Journal**:
   - In the student profile modal, find the "Quick Actions" section
   - Click the "Export Payment Journal" button (golden gradient)
   - PDF will automatically download

3. **Mark Payments as Paid**:
   - When you mark a payment as paid, it's automatically added to the payment history
   - This history is included in future payment journal exports

### For Students

Students do not have direct access to the payment journal. Admins can:
- Generate and download the PDF
- Email it to students if needed
- Print it for physical records

## 📊 Payment History Tracking

### When Records Are Created

Payment history records are automatically created when:
- An admin clicks "Mark as Paid" for a student
- The payment status changes from "pending" or "overdue" to "paid"

### What Gets Tracked

Each payment record includes:
- **Student Information**: Name, formation, branch
- **Payment Details**: Amount, payment date
- **Admin Action**: Who marked it paid, when it was marked
- **Metadata**: Timestamps, notes

### Historical Payments

**Important**: The system only tracks payments marked as paid **after** this feature was implemented. 

For students with previous payments:
- Only future payments (marked after feature deployment) will appear in the journal
- Historical payments before this feature are not retroactively tracked
- The PDF will show "No payment history available" if no payments have been marked since feature deployment

## ⚙️ Configuration

### File Size Limits
- **Target**: 1 MB
- **Maximum**: 1.5 MB
- **Compression**: Enabled by default

To adjust limits, modify `paymentJournalGenerator.js`:
```javascript
if (sizeInMB > 1.5) {
    console.warn('⚠️ Payment Journal PDF exceeds 1.5 MB limit');
}
```

### Table Layout
To modify column widths, edit `paymentJournalGenerator.js`:
```javascript
const columnWidths = [140, 90, 130, 135]; // Adjust these values
const columnX = [50, 190, 280, 410];      // Adjust X positions
```

## 🐛 Troubleshooting

### PDF Not Downloading
1. Check browser console for errors
2. Verify admin is authenticated (JWT token valid)
3. Check server logs for PDF generation errors
4. Ensure student ID is valid

### Empty Payment History
- **Cause**: No payments have been marked as paid since feature deployment
- **Solution**: Mark a payment as paid to create the first history record
- **Note**: Historical payments before feature deployment are not tracked

### PDF Size Too Large
- **Cause**: Very long payment history (50+ payments)
- **Solution**: System automatically compresses PDFs
- **Note**: Pagination handles large datasets efficiently

### Button Not Appearing
1. Verify `phase2-student-profile.js` is loaded
2. Check for JavaScript errors in console
3. Ensure student profile modal is properly rendered
4. Clear browser cache and reload

## 📊 Database Queries

### Get All Payments for a Student
```javascript
const payments = await PaymentHistory.find({ student: studentId })
    .sort({ paymentDate: -1 })
    .lean();
```

### Get Recent Payments (Last 6 Months)
```javascript
const sixMonthsAgo = new Date();
sixMonthsAgo.setMonth(sixMonthsAgo.getMonth() - 6);

const recentPayments = await PaymentHistory.find({
    student: studentId,
    paymentDate: { $gte: sixMonthsAgo }
}).sort({ paymentDate: -1 });
```

### Get Payments by Admin
```javascript
const adminPayments = await PaymentHistory.find({
    markedBy: adminId
}).populate('student', 'fullName');
```
