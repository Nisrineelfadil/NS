## How Translations Work

### Automatic Translation System
The system uses `data-i18n` attributes in HTML and translation functions in JavaScript:

```html
<!-- HTML Example -->
<span data-i18n="studentGrades">Student Grades</span>

<!-- JavaScript automatically translates based on selected language -->
```

### Translation Function
```javascript
// In JavaScript files
const text = t('studentGrades'); // Returns "Schülernoten" in German
```
