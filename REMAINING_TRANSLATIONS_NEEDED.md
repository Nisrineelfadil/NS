## How to Fix

### Method 1: Find and Update JavaScript Files

1. **Search for the text** in JavaScript files:
```bash
# Example: Find "Total Records"
findstr /S /I "Total Records" js\*.js
```

2. **Replace hardcoded text with translation function:**
```javascript
// BEFORE:
innerHTML = `<h3>Total Records</h3>`;

// AFTER:
innerHTML = `<h3>${t('totalRecords')}</h3>`;
```

3. **For table headers:**
```javascript
// BEFORE:
const headers = ['Date', 'Student', 'Group', 'Status'];

// AFTER:
const headers = [t('date'), t('student'), t('group'), t('status')];
```

### Method 2: Quick Search Commands

Run these in the `/js/` folder to find where text is generated:

```bash
# Find Payment Reminders generation
findstr /S /I "Due in 15 Days" *.js

# Find Attendance Stats generation
findstr /S /I "Total Records" *.js
findstr /S /I "Attendance Rate" *.js

# Find Attendance Records generation
findstr /S /I "Attendance Records" *.js
findstr /S /I "Export Group Excel" *.js

# Find Teacher table generation
findstr /S /I "Assigned Groups" *.js
```

```javascript
    return `
        <div class="stat-card">
            <h3>Total Records</h3>
```

Update to:
```javascript

    return `
        <div class="stat-card">
            <h3>${t('totalRecords')}</h3>
            <div>${stats.total}</div>
        </div>
        <div class="stat-card">
            <h3>${t('present')}</h3>
```
