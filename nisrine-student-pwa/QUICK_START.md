# 🚀 Quick Start - Test PWA with Deployed Backend

## ✅ All Set Up!

Your PWA is now configured to use your deployed backend:
**https://nisrinesschool.vercel.app**

## Test Locally (3 Steps)

### 1. Install Dependencies
```bash
cd nisrine-student-pwa
npm install
```

### 2. Start Development Server
```bash
npm start
```

### 3. Test in Browser
- Opens automatically at `http://localhost:3000`
- Login with any student account
- Test all features

## Student Login Example

```
Email: studentname@nisrineschool.com
Password: (set by admin)
```

## Deploy PWA to Production

### Build
```bash
npm run build
```

### Deploy to Vercel
```bash
vercel
```

Your PWA will be live at: `https://your-pwa-name.vercel.app`

## What's Configured

✅ API URL points to deployed backend  
✅ All screens updated to use config  
✅ CORS should work (same domain or configured)  
✅ PWA features enabled (install, offline, etc.)
