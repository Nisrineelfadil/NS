⚠ Faux Positifs du Diagnostic Initial
🔴
FP-1 · "Injection SQL détectée sur les endpoints API"
Le backend utilise MongoDB + Mongoose ODM — aucune base SQL. OWASP ZAP envoie des payloads SQL génériques (' OR 1=1 --) sans connaître la stack. Mongoose protège contre les injections NoSQL. Action préventive : mongo-sanitize ajouté (fix #10).
FAUX POSITIF — ZAP sans contexte stack
🔴
FP-2 · "Paramètre ?cin= visible dans les URLs"
Le CIN n'a jamais été envoyé en GET — uniquement via POST body (FormData). Aucune route backend n'utilise req.query.cin ni req.params.cin. Action préventive : CIN retiré du formulaire public (fix #2).
FAUX POSITIF — Confusion DOM vs URL param
🔴
FP-3 · "Photos étudiants dans /Img/ sans contrôle d'accès"
Le dossier /Img/ contient uniquement des assets du site (logo, images services). Les vraies photos sont stockées dans Mega.nz ou en base64 dans MongoDB, servies via des endpoints authentifiés. Action ciblée : /uploads/ protégé par JWT (fix #3).
FAUX POSITIF — Mauvais dossier ciblé
🟡
FP-4 · "2ème certificat SSL non fiable (no-sni.vercel-infra.com)"
Comportement standard de l'infrastructure Vercel. Quand un client se connecte sans SNI, Vercel retourne son certificat par défaut. Tous les navigateurs modernes supportent SNI. Aucune action nécessaire.
NON-BUG — Infrastructure Vercel standard
🟡
FP-5 · "Codes 2FA incorrects / reçus trop tard en production"
Deux causes réelles : (1) Vercel tue les tâches en arrière-plan après res.json() → email jamais envoyé en prod. (2) L'utilisateur lisait d'anciens emails. Résolu par fix #15 (await email + expiry 10 min).
MALENTENDU — Cause serverless + confusion email
🟢
FP-6 · "Lazy loading manquant sur les images"
Toutes les images de la galerie ont loading="lazy" — galerie, affichage principal et iframe Google Maps. Le diagnostic n'a pas détecté l'attribut HTML5 natif.
FAUX POSITIF — Déjà implémenté (HTML5 native)
🟢
FP-7 · "Schema.org LocalBusiness manquant"
JSON-LD complet avec @type: "EducationalOrganization" présent dans index.html — géocoordonnées, adresse, cours, contact multilingue, areaServed. Plus approprié que LocalBusiness pour une école.
FAUX POSITIF — Schema.org correct (EducationalOrganization)
🟢
FP-8 · "Google reCAPTCHA non configuré"
reCAPTCHA v3 déjà intégré sur tous les formulaires publics (fix #13) : Contact, Rating, Registration, CV, Translation, Job Applications — 6 endpoints protégés avec middleware côté serveur + tokens frontend.
FAUX POSITIF — reCAPTCHA v3 déjà actif
🟢
FP-9 · "Cookie consent RGPD manquant"
Banner de consentement cookies déjà implémenté dans index.html (fix #11) — conforme RGPD avec boutons Accepter/Refuser, stockage localStorage, pas de cookies publicitaires tiers.
FAUX POSITIF — Banner cookies déjà actif
