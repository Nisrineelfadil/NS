## How It Works

### Static Content
Static text uses `data-i18n` attributes that are automatically translated by the `applyTranslations()` function in `admin-dashboard.js`:

```html
<h3 data-i18n="admin.appointments.todays_appointments">Today's Appointments</h3>
```

### Dynamic Content
Dynamic content (generated by JavaScript) uses the `t()` helper function:

```javascript
function t(key) {
    if (!window.translations || !window.currentLanguage) return key;
    const keys = key.split('.');
    let value = window.translations[window.currentLanguage]?.translations;
    for (const k of keys) {
        value = value?.[k];
    }
    return value || key;
}

// Usage
const statusLabel = t('admin.appointments.' + appointment.status);
```

### Automatic Language Switching
When the admin changes the language:
1. Static elements update automatically via `applyTranslations()`
2. Dynamic content updates when data is reloaded
3. No page refresh needed
