# App Icons

Place your app icons here:

- **icon.png** - 512x512 PNG for Linux
- **icon.ico** - 256x256 ICO for Windows  
- **icon.icns** - 512x512 ICNS for macOS

## Quick Icon Generation

You can use your school logo and convert it online:
- https://www.icoconverter.com/ (for .ico)
- https://cloudconvert.com/png-to-icns (for .icns)
- Or just use a 512x512 PNG for all platforms

## Temporary Solution

If you don't have icons yet, the app will use Electron's default icon.
