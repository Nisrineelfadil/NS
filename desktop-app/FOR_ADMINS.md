# Nisrine School Admin Desktop App - User Guide

## 📥 Installation (One-Time Setup)

### Step 1: Download
- Get the file: `Nisrine School Admin Setup 1.0.0.exe`
- Save it to your computer

### Step 2: Install
1. Double-click the installer file
2. Click "Next"
3. Choose install location (or keep default)
4. Click "Install"
5. Wait for installation to complete
6. Click "Finish"

### Step 3: Open the App
- Find "Nisrine School Admin" in your Start Menu
- Or double-click the desktop shortcut
- The app will open

### Step 4: Login
- Enter your admin email
- Enter your admin password
- Click "Login"
- You're in! 🎉

## 🔔 How Notifications Work

### Automatic Notifications:

When something happens (new registration, rating, message, etc.):

1. **Within 30 seconds**, you'll see:
   - 📱 Windows notification popup (bottom-right corner)
   - 🔔 Sound alert
   - 📊 Number appears in system tray icon
   - ✨ Notification in the app

2. **Click the notification** to see details

3. **No need to refresh!** Everything is automatic

### Where to Find Notifications:

- **Bell icon** (top-right corner of app)
- **System tray** (bottom-right of Windows taskbar)
- **Windows Action Center** (Windows key + A)

## 🎯 Daily Use

### Opening the App:
- Click the icon in Start Menu
- Or click the desktop shortcut
- Or click the system tray icon (bottom-right)

### Closing the App:
- Click the X button (app stays in system tray)
- Right-click system tray icon → Quit (fully closes)

### Minimizing:
- Click minimize button (app goes to system tray)
- Click system tray icon to bring it back

## 💡 Tips & Tricks

### System Tray:
- **Look for the app icon** in the bottom-right corner of Windows
- **Right-click** to see menu
- **Click** to show/hide the app
- **Shows notification count**: "Notifications: 3"

### Keyboard Shortcuts:
- **Ctrl+R** - Refresh the page
- **Ctrl+Shift+R** - Force refresh (if something looks broken)
- **F12** - Open developer tools (for troubleshooting)
- **F11** - Fullscreen mode
- **Ctrl+Q** - Quit the app

### Sounds:
- Notification sounds use Windows system sounds
- To change: Windows Settings → System → Sound → Notifications
- To mute: Use Windows volume mixer

## ❓ Common Questions

### Q: Do I need internet?
**A:** Yes, the app needs internet to connect to the school's server.

### Q: Do I need to install anything else?
**A:** No, just the app. Everything else is automatic.

### Q: Where is my data stored?
**A:** All data is stored securely in the cloud. Nothing is saved on your computer.

### Q: Can I use it on multiple computers?
**A:** Yes! Install on as many computers as you want. Login with the same credentials.

### Q: Will I lose my data if I uninstall?
**A:** No, all data is in the cloud. You can reinstall anytime.

### Q: How do I update the app?
**A:** Download the new installer and install it. Your settings will be kept.

## 🐛 Troubleshooting

### App won't open:
1. Check if it's already running (look in system tray)
2. Restart your computer
3. Reinstall the app

### Can't login:
1. Check your email and password
2. Check internet connection
3. Try the website: https://nisrine-school.vercel.app/admin
4. Contact support if website also doesn't work

### No notifications:
1. Wait 30 seconds after an event
2. Check if you're logged in
3. Check internet connection
4. Click the bell icon to refresh

### White screen:
1. Wait a few seconds (it's loading)
2. Check internet connection
3. Press Ctrl+Shift+R to force refresh
4. Restart the app

### App is slow:
1. Check internet speed
2. Close other programs
3. Restart the app
4. Restart your computer
