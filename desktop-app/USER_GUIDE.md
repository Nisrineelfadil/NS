# User Guide - Nisrine School Admin Desktop App

## For Admins (Non-Technical Users)

### ✅ Installation

1. **Download** the installer:
   - File name: `Nisrine School Admin Setup 1.0.1.exe`
   - Size: ~150 MB

2. **Run** the installer:
   - Double-click the `.exe` file
   - Click "Next" → "Next" → "Install"
   - Wait for installation to complete

3. **Launch** the app:
   - Desktop shortcut will be created
   - Or find in Start Menu: "Nisrine School Admin"

### 🚀 First Time Use

1. **Open the app** (double-click desktop icon)
2. **Wait** 2-3 seconds for loading screen
3. **Login** with your admin credentials
4. **Start working!**

### 💡 Daily Use

- **Open**: Double-click desktop icon
- **Close**: Click X button (or minimize to tray)
- **Reopen**: Click tray icon or desktop shortcut

### 🌐 Internet Required

- ✅ **YES** - Internet connection required
- 📡 Connects to: `https://nisrine-school.vercel.app`
- 🔒 Secure HTTPS connection

### ❓ Troubleshooting

#### App won't open?
- Check internet connection
- Restart computer
- Reinstall the app

#### Slow loading?
- Check internet speed
- Close other programs
- Wait 5-10 seconds (server warming up)

#### Can't login?
- Check username/password
- Contact IT support
- Try web version first
