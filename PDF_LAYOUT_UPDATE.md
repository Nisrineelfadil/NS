## 🔄 Dynamic Positioning

The layout uses `currentY` variable to track vertical position:

1. **Logo**: currentY = 40
2. **School Name**: currentY += (logoHeight + 15)
3. **Report Title**: currentY += 35
4. **Group**: currentY += 35
5. **Season**: currentY += 20
6. **Date**: currentY += 20
7. **Line separator**: currentY += 25
8. **Summary**: currentY += 20
9. **Table**: Continues from currentY

This ensures proper spacing even if logo is missing or content varies.
