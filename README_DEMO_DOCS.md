## 🚨 EMERGENCY QUICK FIXES

### Server won't start
```bash
netstat -ano | findstr :3000
taskkill /PID [PID] /F
npm start
```

### MongoDB connection failed
- Check .env file has MONGODB_URI
- Verify internet connection

### No data showing
```bash
node scripts/generate-test-students.js
```

### Login not working
```javascript
localStorage.clear();
sessionStorage.clear();
// Refresh page
```
