# Student ID Card Generator - Quick Start Guide

## 🚀 Quick Access

### From Students Grid
1. Go to **Students** tab
2. Click the **blue ID card icon** button on any student card
3. Card modal opens instantly

### From Student Profile
1. Click **View Details** on any student
2. Click **"Carte d'Étudiant"** (golden button at top of Quick Actions)
3. Card modal opens with both sides

## 📋 Card Contents

### Front Side (French)
- 🏫 School logo and name
- 📸 Student photo
- 🆔 Student ID
- 📚 Branch/Formation
- 📞 Phone number
- 📅 Academic session
- 📊 Barcode

### Back Side (French)
- 📧 School email
- 🔑 Password
- 📱 QR code (links to profile)

## 🖨️ Printing

1. Click **"Imprimer la Carte"** button
2. Select printer
3. Print both sides
4. Done! ✅

## 💾 Download PDF

1. Click **"Télécharger PDF"** button
2. PDF auto-downloads
3. File: `Carte_Etudiant_[Name].pdf`

- **Language**: All card text is in French
- **Logo**: Uses school logo from `Img/logo.png`
- **No Branch**: Shows "Aucune formation" if student has no branch
- **Password**: Displayed in plain text on back (for student reference)
- **QR Code**: Links to student's digital profile

## 🔧 Troubleshooting

| Issue | Solution |
|-------|----------|
| Barcode missing | Refresh page, check console |
| QR code missing | Refresh page, libraries may not be loaded |
| PDF fails | Use print function instead |
| Photo missing | Default avatar shows automatically |

1. **Print Quality**: Use high-quality printer for best results
