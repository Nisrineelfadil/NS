# 🚀 Attendance Export - Quick Start Guide

## 📋 What You Can Do

Export monthly attendance sheets in **PDF** or **Excel** format for any group, season, and month.

---

## 🎯 How to Export Attendance

### Step 1: Open the Export Modal
1. Go to **Student Management** page
2. Click on **"Attendance"** tab in the sidebar
3. Click the **"Export Monthly Attendance"** button (top section)

### Step 2: Fill in the Required Fields

#### Select Group *
- Choose the group you want to export
- Example: "Group A", "Group B", etc.

#### Select Season *
- Choose the academic season
- Example: "2025-2026 (active)"

#### Select Month & Year *
- **Month**: Choose from January to December
- **Year**: Choose the year (defaults to current year)
- Example: "Octobre (October)" + "2025"

### Step 3: Choose Export Format

Click one of these buttons:
- **📄 Export PDF** - For printing and official reports
- **📊 Export Excel** - For data analysis and editing

### Step 4: Download & Open

- File downloads automatically
- Check your Downloads folder
- Open with PDF reader or Excel

## ⚠️ Important Notes

### Required Fields:
All fields marked with a red asterisk (*) are **required**:
- ✅ Group
- ✅ Season
- ✅ Month
- ✅ Year

### Validation:
If you forget a field, you'll see a warning message:
- ⚠️ "Please select a group before exporting."
- ⚠️ "Please select a season before exporting."
- ⚠️ "Please select a month before exporting."
- ⚠️ "Please select a year before exporting."

### File Names:
Files are automatically named:
- **PDF**: `Rapport-Presence-GroupA-Octobre-2025.pdf`
- **Excel**: `Rapport-Presence-GroupA-Octobre-2025.xlsx`

## 💡 Tips & Tricks

### For Best Results:
1. **Use PDF for**:
   - Printing physical copies
   - Official documentation
   - Sharing with parents
   - Archive purposes

2. **Use Excel for**:
   - Data analysis
   - Creating charts
   - Editing data
   - Importing to other systems

### Time-Saving Tips:
- Year is auto-selected to current year
- Modal remembers your last selections
- Export multiple months by changing only the month field
- Close modal with ESC key or X button

## 🐛 Troubleshooting

### Problem: Export button does nothing
**Solution**: Make sure all 4 fields are selected

### Problem: Season dropdown is empty
**Solution**: Contact admin to create seasons in the system

### Problem: No data in report
**Solution**: Verify that attendance was recorded for that month

### Problem: Download doesn't start
**Solution**: Check browser popup blocker settings

## 🎉 Quick Example

**Scenario**: Export October 2025 attendance for Group A

1. Click **"Export Monthly Attendance"**
2. Select **"Group A"** from Group dropdown
3. Select **"2025-2026"** from Season dropdown
4. Select **"Octobre (October)"** from Month dropdown
5. Select **"2025"** from Year dropdown
6. Click **"Export PDF"** or **"Export Excel"**
7. ✅ Done! File downloads automatically

**Result**: Professional attendance report ready to use!
