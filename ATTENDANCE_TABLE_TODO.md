## Quick Fix If You Find The Code

If the table is generated like this:
```javascript
const headers = ['Date', 'Student', 'Group', 'Formation', 'Teacher', 'Status', 'Scan Time'];

});
```

Change to:
```javascript
const headerKeys = ['date', 'student', 'group', 'formation', 'teacher', 'status', 'scanTime'];
headerKeys.forEach(key => {
    html += `<th>${t(key)}</th>`;
});
```
